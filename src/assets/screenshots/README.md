# Ekran Görüntüleri

Bu klasör sunum (presentation) sayfasında kullanılan ekran görüntülerini içerir.

## Gerekli Dosyalar:

✅ Mevcut:
- `dashboard.png` - Dashboard/Ana sayfa görünümü
- `materials.png` - Malzeme listesi sayfası
- `material-new.png` - Yeni malzeme ekleme formu
- `material-bulk.png` - Toplu malzeme yükleme ekranı
- `material-detail.png` - Malzeme detay görünümü
- `material-extend.png` - Malzeme genişletme formu
- `material-change.png` - Tanım değişikliği formu
- `approvals.png` - Onay süreci (eski sistem)
- `reports.png` - Admin raporları sayfası
- `rules.png` - Malzeme kuralları sayfası

🔴 Eksik (Eklenecek):
- `tickets.png` - **YENİ** Ticket listesi sayfası
- `ticket-detail.png` - **YENİ** Ticket detay ve onay ekranı

## Ekran Görüntüsü Nasıl Alınır:

1. Uygulamayı çalıştır: `npm run dev`
2. İlgili sayfaya git:
   - Tickets: `http://localhost:5173/tickets`
   - Ticket Detail: Bir ticket'a tıkla
3. Ekran görüntüsü al:
   - **Windows**: `Win + Shift + S`
   - **Mac**: `Cmd + Shift + 4`
4. Dosyayı bu klasöre kaydet

## İpuçları:
- ✅ 1920x1080 çözünürlük kullan
- ✅ PNG formatında kaydet
- ✅ Gerçek veriyi göster (boş sayfalar değil)
- ✅ Tarayıcı mockup otomatik eklenir
